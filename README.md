## 白皮书简介

《2025 游戏安全白皮书》围绕 AI 时代下的游戏安全攻防变化展开，系统梳理了外挂、黑产、账号安全、内容安全、经济安全、海外安全、法律法规与行业共建等多个方向。

白皮书重点关注以下议题：

- AI 对游戏安全攻防格局的重塑
- PC 与移动端外挂样本、外挂功能与黑产规模变化
- DMA 硬件外挂、AI 视觉外挂、CaaS 作弊服务等新型威胁
- 游戏账号盗号、社工诈骗、黑产交易与经济系统风险
- AIGC 内容安全、语音安全、UGC 场景审核等治理挑战
- 游戏出海背景下的全球化安全运营与合规要求
- 反外挂、风控、内容审核、Replay 行为检测等防御方案
- 游戏安全相关法律法规、司法实践与行业标准建设
